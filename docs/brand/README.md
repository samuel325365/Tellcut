# Tellcut logo

A black and cream dachshund whose long body is a strip of film. Every file here is written by `npm run brand-assets` from the one shape in [`packages/plugin-common/src/dachshund.ts`](../../packages/plugin-common/src/dachshund.ts); change the shape there and run it again rather than editing these files.

| File | Use |
|---|---|
| `tellcut-logo.svg` | The dog on a light background. Its sprocket holes are cut out, so it can be extruded in 3D (`tellcut logo`). |
| `tellcut-logo-dark.svg` | The cream dog, for a dark background. |
| `tellcut-lockup.svg`, `tellcut-lockup-dark.svg` | The dog with "Tellcut" and "Tell it. Cut it." (the words are paths, no font needed). |
| `tellcut-icon.svg`, `tellcut-icon-dark.svg` | The app icon: the dog on a rounded cream or black tile, without the small details. |
| `tellcut-icon-16.svg` | The browser tab icon. |
| `tellcut-icon-{32,64,128,256,512}.png` | The light icon as pictures. |

Colours: black `#161412`, cream `#f4ebdd`, the cream points `#d8b88a`, the ear `#3b342d`. On dark: the dog `#f4ebdd`, the ear `#e3d5bf`, the points `#bea279`.

The wordmark is Nunito ExtraBold (800), under the SIL Open Font Licence.

You may use the logo to point to or write about Tellcut.
